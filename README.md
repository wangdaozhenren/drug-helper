# 用药助手（drug-helper）· 上架清单与使用说明

## 技能概览

- **名称**：用药助手（drug-helper）
- **版本**：2.1.0（免费模式）
- **架构**：本地壳（client-shell）+ FC 后端（fc-backend）
- **数据版本**：2026.09.21-v1
- **核验日期**：2026-09-21
- **数据规模**：15,898 条合并档案（NMPA 156,999条批准 + 医保目录4,843条 + 药典5,699品种 + 小荷医典补爬）
- **技能包体积**：~7MB（精简索引6.97MB，不含完整档案）
- **完整档案存储**：FC 后端（内置高频500条 + OSS全量）
- **收费模式**：**免费**（v2.1.0 起完全免费、无次数限制；付费代码保留，参考 PAYMENT_LOGIC.md）

## 功能清单

### 主路由：药品档案查询
- 药名精确匹配（通用名/商品名/剂型变体）
- 归一化匹配（去剂型后缀/去"注射用"前缀，保留盐类前缀）
- 症状词关联（高血压/糖尿病/感冒/咳嗽等）
- 未命中兜底（可能原因+药品建议+就医指引）

### 副路由：浅层科普（非医疗干预）
- 情绪调节（呼吸法/grounding/认知调整，高风险转介热线）
- 睡眠卫生（作息/环境/睡前习惯）
- 压力管理（减压工具箱）
- 中医养生（四季养生/药食同源，标注非诊疗）
- 正念冥想（呼吸冥想/身体扫描引导，标注非医疗干预）
- 亚健康营养（常见状态调理/营养小贴士）

### 输出
- **免费模式（v2.1.0）**：所有查询直接返回完整档案（功能主治/适应症/用法用量/禁忌/不良反应/相互作用/就医指引 + 来源标注 + 购药入口），完全免费、无次数限制

## 合规红线（不可逾越）

1. **不诊断**：所有输出明确标注"不构成诊断、治疗建议或处方"
2. **不替代医嘱**：处方药必须凭医师处方，特殊人群用药遵医嘱
3. **处方药风险提示**：所有药品输出含处方药使用提示
4. **数据来源可追溯**：每条档案标注数据来源（NMPA/医保/药典）+ 核验日期
5. **信息时效说明**：提示药品标准与医保政策可能更新，以最新官方信息为准
6. **高风险情绪转介**：副路由情绪模块含自伤/自杀念头时，明确转介心理援助热线
7. **中医科普边界**：不承诺疗效，不用"包治/根治"，标注"个体差异请遵医嘱"
8. **正念冥想标注**：明确标注"放松练习，非医疗干预"

### 隐私与数据采集（明示披露）

- **设备标识**：客户端**不采集任何设备硬件信息**（不读取注册表 MachineGuid、C 盘卷序列号等），仅生成一次性随机会话标识（每次进程启动重新生成，不跨会话关联、不落盘、不随请求外发）。
- **邮箱 / 订单号**：仅当用户主动发送「绑定邮箱」「迁移权益」指令时，不上报其他个人信息。
- **查询内容**：仅发送当前查询的药品通用名（query_key），不发送对话全文，不携带任何设备标识。
- **数据存储**：FC 后端不存储设备级计数、不存药品查询历史与个人身份信息。
- **购药链接**：三平台购药参考（京东大药房 / 阿里健康 / 拼多多），京东优先转链短链、失败降级公开搜索；附美团买药本地送药链接与位置引导；技能包不含任何联盟密钥。所有购药链接均明示：「本技能推荐的优惠链接来自平台官方合作渠道。」
- **本技能不含任何 API key/token/secret**；FC 后端地址通过环境变量 `FC_BACKEND_URL` 注入，默认指向第一方后端。
