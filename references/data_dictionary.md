# 数据字典

## 药品档案字段说明

### 精简索引字段（drug_archive_index.json）

| 字段名 | 类型 | 说明 | 来源 |
|--------|------|------|------|
| 药品通用名称 | string | 药品通用名（归一化后的主名称） | NMPA |
| 归一化通用名 | string | 去剂型后缀/去"注射用"前缀后的归一化名 | 计算字段 |
| 剂型变体 | array | 同一通用名下的所有剂型变体名称（如"布洛芬""布洛芬分散片""布洛芬颗粒"） | NMPA合并 |
| 剂型 | array | 剂型列表（如"片剂""胶囊剂""注射剂"），最多5个 | NMPA |
| 规格 | array | 规格列表，最多3个 | NMPA |
| 批准文号 | array | 批准文号列表，最多3个（完整数量见批准文号数字段） | NMPA |
| 批准文号数 | int | 该药品的批准文号总数 | NMPA |
| 上市许可持有人 | array | 上市许可持有人/生产企业列表，最多3个 | NMPA |
| 医保类别 | string | 医保分类："甲"/"乙"/"谈判"/"饮片-予以支付"/"饮片-不予支付"/""（未收录） | 医保目录2025 |
| 医保备注 | string | 医保备注信息（如"限二线用药"） | 医保目录2025 |
| 药典部 | string | 药典分部："一部"/"二部"/"三部"/"四部" | 中国药典2025 |
| 类别 | string | 药典药品分类（如"抗高血压药""清热解毒剂"） | 中国药典2025 |
| 来源 | object | 数据来源标记：{"NMPA": true/false, "医保": true/false, "药典": true/false} | 计算字段 |

### 高频完整档案字段（high_freq_drugs.json）

在精简索引字段基础上，额外包含：

| 字段名 | 类型 | 说明 | 来源 |
|--------|------|------|------|
| 药典功能主治 | string | 中药功能与主治（一部中药） | 中国药典2025一部 |
| 药典用法用量 | string | 用法与用量 | 中国药典2025 |
| 药典禁忌 | string | 禁忌与注意事项 | 中国药典2025 |
| 药典不良反应 | string | 不良反应 | 中国药典2025 |
| 适应症 | string | 化学药适应症（注：药典二部正文为质量标准，此字段多数为空） | 中国药典2025二部 |
| 相互作用 | string | 药物相互作用（如有） | 数据源 |

## 归一化规则

### 规则说明
1. **去剂型后缀**：去掉80+种剂型后缀（片/胶囊/注射液/颗粒/软膏等），按长度降序优先匹配长后缀
2. **去"注射用"前缀**：去掉开头的"注射用"
3. **保留盐类前缀**：盐酸/硫酸/甲磺酸/硝酸等盐类前缀不剥除，避免误合并不同药物
4. **去括号内容**：去掉括号及括号内内容
5. **高置信度判定**：至少去掉了剂型后缀或"注射用"前缀，且归一化后长度≥2

### 示例

|----------|----------|----------|

| 注射用阿奇霉素 | 阿奇霉素 | 是 |

| 硫酸庆大霉素注射液 | 硫酸庆大霉素 | 是 |
| 阿司匹林 | 阿司匹林 | 否（纯通用名） |

## 数据来源

| 数据源 | 官方名称 | 规模 | 采集时间 |
|--------|----------|------|----------|
| NMPA | 国家药品监督管理局药品批准信息 | 156,999条批准记录，18,839个唯一药品 | 2026-09-21 |
| 医保目录 | 国家基本医疗保险、工伤保险和生育保险药品目录（2025年版） | 4,843条（西药1,986+中成药1,440+谈判487+饮片930） | 2026-09-21 |
| 中国药典 | 《中华人民共和国药典》（2025年版）网络版 | 5,699个品种（一部2,280+二部2,771+三部160+四部488） | 2026-09-21 |
